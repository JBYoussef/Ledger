# Ledger

Financial ledger project.

## Environment

- Android 14
- Termux
- Ubuntu 24.04 LTS
- ARM64 / aarch64
- Java 8
- Java 21
- Maven
- PostgreSQL
- Redis
- DuckDB

## Project Structure

- `docs/` — project documentation
- `sql/` — PostgreSQL and analytical SQL
- `java/` — Java applications
- `scripts/` — utility and setup scripts
